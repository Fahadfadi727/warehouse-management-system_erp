# Warehouse Management System

A web-based Warehouse Management System developed for a chemical company to 
digitize and streamline their warehouse operations. The system replaces manual 
record-keeping with a centralized platform for managing inventory, orders, and 
reporting.

## 🔧 Built With
- PHP
- MySQL
- HTML/CSS
- JavaScript

## ✨ Features
- **Inventory Management** — Add, update, and track stock levels of chemical 
  products in real time, reducing manual errors and stockouts.
- **Order Management** — Create, process, and track customer/supplier orders 
  from placement to fulfillment.
- **Reports** — Generate detailed reports on stock levels, order history, and 
  warehouse activity to support better decision-making.
- Secure login system for authorized warehouse staff/admin access.

## 🎯 Purpose
This project was built to solve a real-world problem for a chemical company 
that was managing their warehouse manually, leading to inefficiencies and 
errors. The system improves accuracy, saves time, and gives management 
better visibility into stock and order status.

## 📌 Note
Some data/credentials in this project have been removed or anonymized to 
protect the company's confidential information.
